# Taurus Gym App

App Android basada en la rutina Taurus La Joya.

Incluye rutina lunes a viernes, fotografías reales de referencia para reconocer las máquinas, registro de carga por ejercicio, repeticiones, historial, conversión kg/lb y registro personal.

Las fotografías son referencias visuales de equipos comerciales; la marca o modelo exacto disponible en el gimnasio puede variar.

## APK
La acción de GitHub `Compilar APK Android` genera `app-debug.apk` y lo publica como artefacto `TaurusGymApp-APK`.
